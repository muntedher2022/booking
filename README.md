# 📅 نظام الحجوزات والمساعد الذكي (Ports Booking & AI System)
> منصة ذكية لجدولة الحجوزات وإدارة المحادثات التفاعلية المدعومة بالذكاء الاصطناعي.

---

## 📋 نبذة عن النظام
نظام يدمج بين جدولة الحجوزات وإدارة الجلسات المتصلة، مع واجهة محادثة ذكية (AI Conversations & Messages) لتقديم الدعم الفني وتسهيل الاستعلام عن الخدمات.

## ✨ الميزات الرئيسية
* **إدارة الحجوزات والجلسات:** متابعة المواعيد والجلسات النشطة للمستخدمين.
* **محادثات الذكاء الاصطناعي (AI Messages):** أرشفة الأسئلة والردود الآلية وتسهيل استرجاع سجلات المحادثات.
* **مراقبة الاتصال (Online Sessions):** تتبع الجلسات الفعالة للمستخدمين في الوقت الفعلي.
* **إدارة الصلاحيات:** أدوار متعددة للتحكم في الوصول إلى البيانات.

## 🛠️ التقنيات المستخدمة
* **Framework:** Laravel 11
* **Language:** PHP 8.4
* **Database:** MySQL

## 🚀 التشغيل المحلي
```bash
composer install
php artisan migrate --seed
php artisan serve
```
* **رابط الموقع المحلي:** `https://booking.test`
* **بيانات الدخول:** مراجعة ملف `USERS_CREDENTIALS.md`
